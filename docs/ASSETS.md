## 3D Signal Sage

- File: `static/models/signal-sage.glb`
- Created: 2026-09-01
- Source: original procedural model generated by `tools/blender/build_sage.py`
- Rebuild: `npm run build:sage` using the pinned repository Docker image
- Rights note: original project-specific geometry, rig, materials, chair, CRT face, and animation; no third-party mesh or motion data is included
- SHA-256: `0f9f900305277a6d0b6ca5208c661ee79f0658bf9cfb287b718f0c0a5017b880`
- Geometry: 6,234 uploaded vertices and 8,892 rendered vertices
- Animation clips: `idle`, `talk`, `attentive`, `ascend`, `drop`, `reaction`, `thinking`, `approval`, `confusion`, `suspicious`, `shocked`, `smug`, `lie`, `chair_wobble`, `popup_notice`, `popup_swat`, `weak_answer`, `workstation_exit`, `workstation_push`, `workstation_park`, `workstation_turn`, `research_typing`, `research_one_hand`, `research_inspect`, `research_smack`, `research_cable`, `research_sleep`, `research_celebrate`, `research_complete`, `scroll_present`, `mail_notice`, `mail_click`, `reveal`, `defeat`, and `forbidden`

The model deliberately uses rigid low-poly parts parented to an armature. Its pose keys use constant interpolation so the character can move on twos at 12 unique poses per second while the browser keeps the camera, chair drift, and CRT effects fluid. Sage uses 72% body proportions with a slightly oversized CRT head and hands. The racing-style chair has a tall bucket back, shoulder wings, headrest slots, side bolsters, T-shaped armrests, recline hinges, glowing piping, and a five-fin hover base. The hat crown and robe lap have separate secondary bones for delayed motion. The browser applies the live CRT expression, speech meter, and cursor gaze after sampling each authored pose. Neutral, swat, reveal, and three-quarter proof renders are written under `artifacts/` and intentionally ignored by Git.

The candidates below were evaluated for the proof-of-style workstream but were not included. Building the monitor head, robe, hands, rig, and chair as one small procedural character produced a more specific silhouette and removed asset-pack seams while keeping the model reproducible.

The final Sage must not look like an unchanged asset-pack character. The body proportions, monitor silhouette, chair, clothing, textures, CRT face, and animation timing form one original assembled design. ## Native pixel Sage portraits

- Files: `static/images/sage-pixel/{neutral,thinking,suspicious,delighted,irritated,shocked,smug,defeated,forbidden}.svg`
- Native grid: 64 by 64 pixels, whole-pixel contours, fewer than 24 colors per portrait
- Created: 2026-09-04
- Source: original vector pixel drawings in `scripts/build-pixel-portraits.mjs`
- Rebuild: `npm run build:sage-portraits`, with no input image or external service
- Rights: original project artwork; no downloaded images or reference meshes
- Display: 128-pixel dialogue portraits on desktop, 64 pixels on mobile; nearest-neighbor rendering
- Contact sheet: `artifacts/design-pass/portraits.png`

All nine portraits share the CRT casing, crooked star hat, robe, spherical hands, and chair. Eye clusters, brows, mouth shapes, accent colors, and three small reaction symbols distinguish the moods. The monochrome PNGs and painted source sheet remain as historical assets, but the game, menu, login, and concept dossiers use the new SVG portraits.

The matching choice cursor, `static/images/ui/choice-hand.svg`, is an original 16×16 vector pixel drawing made for this interface. The current portrait, cursor, and model hashes are recorded in `artifacts/design-pass/asset-sha256.txt`.

The September 4 design pass also rebaked all 35 model clips. Body poses hold on twos at a 24 fps base, with smoothstep in-betweens between the original authored poses. Chair and root transforms use linear interpolation. Listening takes six seconds per loop, and ordinary speech gestures take three seconds. The renderer blends action weights using elapsed animation time, pauses while hidden or behind the menu, and applies facial color without overexposing amber to white. See `docs/DESIGN-PASS.md` for verification evidence.
